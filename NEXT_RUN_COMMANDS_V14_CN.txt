1. 快速数据诊断（先小样本）
---------------------------

mkdir -p "$OUT_ROOT/eval" "$OUT_ROOT/logs"

# 1.1 raw/transport 对齐：默认 sampled hash + selective NPZ read + 8 workers
python -u -m cowp.scripts.33_diagnose_cache_alignment \
  --raw-cache "$RAW_TRAIN_CACHE" \
  --transport-cache "$TRAIN_CACHE" \
  --max-scenes 256 \
  --workers "$DIAG_WORKERS" \
  --hash-mode sampled \
  --output "$OUT_ROOT/eval/cache_alignment_train_smoke.json" \
  2>&1 | tee "$OUT_ROOT/logs/cache_alignment_train_smoke.log"

python -u -m cowp.scripts.33_diagnose_cache_alignment \
  --raw-cache "$RAW_VAL_CACHE" \
  --transport-cache "$VAL_CACHE" \
  --max-scenes 256 \
  --workers "$DIAG_WORKERS" \
  --hash-mode sampled \
  --output "$OUT_ROOT/eval/cache_alignment_val_smoke.json" \
  2>&1 | tee "$OUT_ROOT/logs/cache_alignment_val_smoke.log"

# 1.2 label-only运动学 oracle：先 500 scenes
python -u -m cowp.scripts.34_diagnose_natural_oracles \
  --cache-dir "$RAW_VAL_CACHE" \
  --max-scenes 500 \
  --workers "$DIAG_WORKERS" \
  --output "$OUT_ROOT/eval/natural_oracle_val_smoke.json" \
  2>&1 | tee "$OUT_ROOT/logs/natural_oracle_val_smoke.log"

# 1.3 最关键：复现训练实际路径的 model-anchor preflight
python -u -m cowp.scripts.35_diagnose_model_anchor \
  --data-config configs/data.yaml \
  --model-config configs/model.yaml \
  --label-config configs/label_cowp_v14.yaml \
  --train-config configs/train_cowp_v14.yaml \
  --cache-dir "$RAW_VAL_CACHE" \
  --max-scenes 500 \
  --batch-size 16 \
  --num-workers "$DIAG_WORKERS" \
  --device cpu \
  --output "$OUT_ROOT/eval/model_anchor_preflight_val_smoke.json" \
  2>&1 | tee "$OUT_ROOT/logs/model_anchor_preflight_val_smoke.log"

三个命令必须 exit code=0。
重点检查 model_anchor_preflight_val_smoke.json：
- pass=true
- critical_unmapped_or_invisible <= 0.02
- gt_first_step_vs_model_cv_anchor_m.p90 <= 5.0
- typed_basis/1s.mean <= 3.0
- typed_basis/8s.mean <= 8.5

若 35 失败：
- input_index_vs_original_track_index_anchor_delta 很大：重点查 proto track_index 到 tf.Example row 的映射；
- first-step p90 很大但 input_index delta 不大：重点查坐标系/当前帧时间索引；
- unmapped rate 很大：重点查 max_agents、筛选和 input_index 缺失；
- first-step正常但 8s差：再查 natural label与运动学先验，不要先改 planner。

8. 论文必要的后续协议
---------------------

当前 driver 的 Waymax online evaluator明确是 SDC closed-loop + logged non-ego replay。
论文核心命题还需要另行注册：
- Waymax IDM non-ego；
- learned reactive traffic agent；
- non-ego induced deceleration / jerk / gap surrender / priority abandonment；
- paired counterfactual candidate rollout；
- 小规模专家人工审计。

在这些协议实现并验证前，不得把 logged-replay 结果写成 reactive multi-agent 证据。
